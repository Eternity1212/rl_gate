## 1. 直接对照

| 方法 | 核心公式/操作 | TRIAGE 多做什么 |
|------|----------------|-----------------|
| **GRPO + ORM** (DeepSeek-Math / R1 线) | 组内对 \(r_o\) 归一 | 引入过程分与四格 |
| **P-GRPO** (arXiv:2508.05170) | \(R=R_o+R_o\cdot R_t\) | 区分 W↑/W↓；W↓ 用 LENS；W↑ 过滤 |
| **PAPO** (arXiv:2603.26535) | \(A_o+A_p\)（\(A_p\) 仅正确子集） | 增加错误侧分流；不只置零过程 |
| **PROF** (arXiv:2509.03403) | 过滤冲突样本再 ORM-GRPO | 不过度丢弃 C↓；C↓ 用相对抑制而非一律删除 |
| **PROGRS** (arXiv:2604.02341) | 错误子集过程 centering | 主文以 filter/LENS 为主；附录可对比 centering |
| **LENS** (arXiv:2510.08696) | 错答置信惩罚 | 仅施加于 W↓，且与过程分联立 |
| **Step-GRPO** (AAAI 2026) | 步注意力聚合 PRM | 不同问题；可作低成本实验规模参考 |
| **PURE** (min-form) | 过程信用取 min | 正交；可不作为主基线 |

## 2. 原 GatePO 为何放弃

GatePO ≈ PAPO 的解耦 + P-GRPO 的门控 + 额外 \(A_h\)。  
增量无法通过「是否已有论文」审查。TRIAGE 的贡献在于 **2×2 一致性分类学 + 四算子必要性消融**，不是又一个门控系数。

---

## 3. 写作时必须回答的审稿问题

1. Q: 这不就是 PAPO+PROF 吗？  
   A: PAPO 不分流错误侧；PROF 对 C↓ 与 W↑ 同罚（过滤）。消融证明合并格子损害指标。

2. Q: 与 P-GRPO？  
   A: P-GRPO 答错则 \(R_t=0\)，不区分「装得好的错」与「普通错」。

3. Q: 为何不过度依赖新 PRM？  
   A: 主文固定一个 PRM；附录 rule process 证明框架不绑特定神经裁判。

## 4. 创新是否够？还要不要加对比 / SOTA？

### 结论（投稿现实）

- **相对 GatePO**：TRIAGE 更站得住（有 2×2 分类学 + 四算子消融）。  
- **相对领域前沿**：属于 **方法型增量**，不是新 scaling 定律或新大模型；AAAI/Findings **够用的前提**是：同算力下稳定超过 PAPO/P-GRPO/PROF/LENS，且 hack_rate 明显更好。  
- **不要**把主 claim 设成「超过 DeepSeek-R1 / 闭源 o-series 绝对分」——那是算力与数据竞赛，不是本工作定位。

### 当前矩阵已经覆盖的「公平 SOTA 对照」

在同一模型（1.5B）+ 同一数据（DAPO-17k）+ 同一 steps 下：

| 对照 | 作用 |
|------|------|
| ORM-GRPO | 领域默认强基线 |
| P-GRPO / PAPO / PROF / LENS | 最近直接竞品（必须赢或持平且更稳） |
| Naive hybrid / PRM-direct | 展示黑客与冲突 |
| 消融 A1–A6 | 证明四格不能合并 |

这已经是审稿最看重的 **matched-compute SOTA（方法 SOTA）**。

### 建议增加（增强说服力，非阻塞开题）

| 优先级 | 增加项 | 原因 |
|--------|--------|------|
| P0（强烈建议） | 主指标并列报 **准确率 + hack_rate + 平均长度** | 证明「不是靠刷分/变啰嗦」 |
| P0 | 与 **最强单基线（通常是 PAPO）** 画同算力曲线 | 证明后期不塌 |
| P1 | 加 **PROGRS**（错误子集 centering）作附录基线 | 堵住「错误侧还有更好做法」 |
| P1 | 算法骨架附录对比 **DAPO clip**（同一 TRIAGE 奖励） | 证明不绑死 vanilla GRPO |
| P2 | 7B 各跑 ORM vs TRIAGE 各 1 seed | 可扩展性 |
| P2 | 若复现成本可控：Step-GRPO / Dr.GRPO 作相关工作数字对齐 | 非必须复现全训练 |

### 不建议加的「假 SOTA」

- 与未开源、不可复现的工业报告正面比绝对分  
- 换更大私有数据只为涨 AIME  
- 同时改模型+数据+算法却声称方法赢了
